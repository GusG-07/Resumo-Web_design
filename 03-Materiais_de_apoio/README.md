# Ferramentas de IA usadas como apoio

Ferramentas de inteligência artificial utilizadas ao longo do semestre na
disciplina de Web Design, como apoio ao aprendizado e ao desenvolvimento
do projeto final.

| Ferramenta | Empresa | Como foi utilizada |
|------------|---------|--------------------|
| ChatGPT | OpenAI | Dúvidas gerais e aprendizado do conteúdo da disciplina |
| Claude | Anthropic | Principal ferramenta de auxílio no código do projeto SynapseQ |

## ChatGPT: dúvidas gerais e aprendizado

Usado como ferramenta de estudo para:

- Tirar dúvidas sobre conceitos de Web Design (HTML, CSS, layout, responsividade)
- Entender o conteúdo das aulas com explicações alternativas
- Revisar e fixar o que foi visto durante o semestre

## Claude: auxílio no projeto SynapseQ

Principal ferramenta de apoio no desenvolvimento do site **SynapseQ**,
projeto realizado ao longo do semestre. Foi utilizado para:

- Estruturar e escrever o código HTML/CSS das páginas
- Entender e corrigir erros de código

O acesso foi feito pela versão paga do Claude de um colega de faculdade,
que também a utilizou no desenvolvimento do projeto.

## Como usei as respostas

As sugestões das IAs foram testadas, revisadas e ajustadas.
Elas serviram como apoio ao aprendizado, e não como substituição do
trabalho feito na disciplina.
