## Sobre o projeto

O projeto é um site para uma empresa fictícia que busca investidores para a construção de um computador quântico.

A empresa pretende construir a tecnologia e alugar ou vender o poder computacional da máquina, e não a máquina em si. Diversos problemas podem ser resolvidos de forma mais eficiente e simples com computação quântica. O público-alvo são estudantes universitários e pesquisadores, cujas pesquisas e desenvolvimentos seriam beneficiados por esse poder computacional.

## Páginas

- Tecnologia
- Casos de uso
- Demo
- Quantum Engineering
- Investidores
- Glossário
- Portal do investidor

## Tecnologias utilizadas

HTML, CSS e JavaScript. Publicado na Vercel.
